# My Pet Hero / 我的寵物勇者

這不再只是普通電子寵物，而是會自己生活、自己找資源、自己闖迷宮成長的 **寵物勇者模擬器**。

## 核心方向

- **不需要背景常駐**
- 只保存上次狀態與少量歷史
- 每次查詢時才根據經過時間推演生活與冒險
- 飢餓或口渴時，角色會自己去找食物或水
- 角色會視狀態、個性與職業，自主去隨機生成的迷宮闖蕩
- 有 **等級、經驗值、金幣、屬性、職業、迷宮進度**
- 產生一張像素風勇者狀態卡 PNG

## 目前支援種族

- 精靈 `elf`
- 矮人 `dwarf`
- 人類 `human`
- 獸人 `orc`
- 龍族 `dragon`

## 目前支援職業

### 狂戰士 `berserker`
- 可使用雙手武器與多種近戰武器
- 厚血、物理抗性高、魔法抗性偏弱
- 不容易被絆倒或限制行動
- **矮人 / 人類有加成**

### 盜賊 `rogue`
- 短刃能力強、可雙持、攻速快、敏捷高
- 具備陷阱偵測、開鎖、潛行能力
- 偏向皮甲
- **人類 / 精靈 / 龍族有加成**

### 法師 `mage`
- 使用法杖，擅長元素、召喚、心控系魔法
- 可製作魔法食物與藥水
- 可開啟城鎮傳送門
- **龍族 / 精靈有加成**

## 設計原則：可擴充職業架構

職業不是寫死在 if/else 裡，而是獨立資料定義，未來可以繼續擴充：
- 新職業配置
- 種族相容加成
- 武器標籤
- 能力標籤
- 推薦職業 / 天賦傾向
- 後續戰鬥與技能系統掛接

## 目前已有系統

- Query-time simulation
- 種族配置系統
- 職業配置系統
- needs 狀態（健康 / 飢餓 / 口渴 / 心情 / 體力 / 整潔）
- hero progression（等級 / 經驗 / 金幣 / 屬性 / 職業傾向）
- 自動 self-care（自己找食物 / 找水）
- 自動 dungeon run（隨機迷宮探索）
- feed / play / clean 基本互動
- PNG 狀態卡輸出

## 指令

```bash
npm run create -- --name Mochi --species dragon --class mage
npm run render -- --id mochi
npm run dev -- classes
npm run dev -- feed --id mochi
npm run dev -- play --id mochi
npm run dev -- clean --id mochi
```

## 資料位置
